Overview

Two analyses, each computed with two feature-selection methods. AUC uses pROC direction="<" throughout.
Method note. Transfer = a GLM refit on the whole source cohort (top-N features) applied to each other cohort — measures generalization across independent cohorts. Combined = the pooled 3-cohort model with 4 batch-handling variants (plain / cov / combat / both), CV-honest ComBat, 100×10 bootstrap; AUC is the mean per-fold AUC. Correlation selection is done inside each training fold (leakage-proof).
Key finding: supervised correlation feature-selection overfits — it transfers worse across cohorts and gives lower combined CV-AUC than unsupervised MAD selection.

Transfer model summary

Each source cohort's whole-dataset GLM (top-N features): number of features / non-zero coefficients, honest within-cohort CV (Source_CV_AUC), and transfer AUC applied to each other cohort.
Source_CV_AUC = mean per-fold AUC of within-cohort CV (fold-internal feature selection). AUC_<cohort> = model applied to that other cohort; the source's own column is blank.
